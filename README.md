# Niranjan — Personal Portfolio

A responsive, static personal website built with HTML, CSS and JavaScript.

## Preview on your Windows 11 computer
1. Extract `niranjan_portfolio.zip`.
2. Open the extracted folder.
3. Double-click `index.html`. It opens in your browser.

No installation or coding tools are required to preview it.

## Customize
- Edit the text in `index.html`.
- Change colours, spacing and layout in `styles.css`.
- Navigation behavior is in `script.js`.

## Publish it
You can host this static site using GitHub Pages:
1. Create a GitHub account and a new public repository.
2. Upload `index.html`, `styles.css` and `script.js` to the repository's root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. GitHub will provide the published website address after deployment.

A public website may be indexed by search engines, but Google listing and ranking are not guaranteed and can take time. Add a Google Search Console property after publishing if you want to request indexing.

## Privacy before publishing
This version uses only the first name you supplied. Do not add your home address, phone number, school timetable, exact school location, personal email, or other private details to a public page.
